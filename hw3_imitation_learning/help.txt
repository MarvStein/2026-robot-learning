Workflow / commands used:

compute actions command used:
python scripts/compute_actions.py --action-space ee

training command used:
python scripts/train.py \
--zarr datasets/processed/single_cube/processed_ee_xyz.zarr \
--state-keys state_ee_xyz state_gripper "state_cube[:3]" state_obstacle \
--action-keys action_ee_xyz action_gripper \
--policy obstacle

evaluation command used:
python scripts/eval.py --checkpoint checkpoints/single_cube/best_model_ee_xyz_obstacle.pt

for submission of ex1:
python student_eval/run_eval.py --exercise 1 --checkpoint checkpoints/single_cube/best_model_ee_xyz_obstacle.pt

then rename the pt file to ex1.pt

for exercise 2:
python scripts/dagger_eval.py \
--checkpoint checkpoints/single_cube/best_model_ee_xyz_obstacle.pt \
--num-episodes 10

then again:
python scripts/compute_actions.py --action-space ee

then retrain:
python scripts/train.py \
--zarr datasets/processed/single_cube/processed_ee_xyz.zarr \
--state-keys state_ee_xyz state_gripper "state_cube[:3]" state_obstacle \
--action-keys action_ee_xyz action_gripper \
--policy obstacle

then evaluate "out of distribution":
python scripts/eval.py \
--checkpoint checkpoints/single_cube/best_model_ee_xyz_obstacle_dagger10ep.pt \
--adversarial \
--headless \
--num-episodes 100

then do dagger again:
python scripts/dagger_eval.py \
--checkpoint checkpoints/single_cube/best_model_ee_xyz_obstacle_dagger10ep.pt \
--num-episodes 10

--> compute actions, retrain and then:
python scripts/eval.py \
--checkpoint checkpoints/single_cube/best_model_ee_xyz_obstacle_dagger20ep.pt \
--adversarial \
--headless \
--num-episodes 100

then rename checkpoints/single_cube/best_model_ee_xyz_obstacle_dagger20ep.pt to ex2.pt
and run:
python student_eval/run_eval.py --exercise 2 --checkpoint checkpoints/single_cube/ex2.pt
